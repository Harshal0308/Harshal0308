## ⭐ Featured Projects

### 💻 CodeCollab — Real-Time Collaborative Coding Platform

A full-stack collaborative coding platform supporting authenticated users, room-based collaboration, shared files, real-time communication, and collaborative code editing.

Implemented **Socket.io-based real-time synchronization**, Monaco Editor integration, JWT authentication with bcrypt password hashing, and WebRTC video-call signaling.

**Tech:** Next.js · React · Node.js · Express.js · MongoDB · Socket.io · Monaco Editor · JWT · WebRTC

🔗 [View Repository](https://github.com/ankitwankhede50-ai/collaborative-coding)

---

### 🤖 HireForge AI — AI-Powered Recruitment Platform

An AI-powered recruitment platform that analyzes resumes against job descriptions using semantic similarity and skill-based matching to rank candidates.

Implemented a **two-stage ranking pipeline** using MiniLM embeddings and cosine similarity for candidate filtering, followed by LLM-based re-ranking to refine final rankings.

**Tech:** Python · FastAPI · PostgreSQL · Sentence Transformers · MiniLM · LLMs

🔗 [View Repository](https://github.com/prathmeshkurhade/ai-recruiter-clg)

---

### 📚 SARAL — AI-Powered Educational Management System

An educational management system designed for volunteer-driven learning centers, developed as part of a **3-member team**.

Contributed to product ideation and implemented the **face-recognition attendance pipeline** using Google ML Kit and TensorFlow Lite embeddings for automated student identification.

**Tech:** Flutter · Supabase · Google ML Kit · TensorFlow Lite
